# 📱 Guilherme Ribeiro - Portfolio

This is my personal portfolio built with **Flutter Web**, responsive and adapted to different screen sizes, including mobile device simulation.

🔗 **Live Demo:**  
👉 [https://guilhermequeirozribeiro.netlify.app](https://guilhermequeirozribeiro.netlify.app)

---

## 🛠️ Technologies Used

- Flutter Web
- Provider (state management)
- Google Fonts
- flutter_svg (for rendering SVG icons)
- device_frame (for device previews)

---

💡 Features

- Navigation between sections and projects
- Device simulation interface
- Clickable external links to social media and work
- Clean, lightweight UI with custom buttons

📦 Deployment
This project is hosted on Netlify, automatically updated after each Flutter Web build.
